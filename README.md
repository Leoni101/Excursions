# Сервис бронирования экскурсий

## Назначение

Приложение предназначено для бронирования экскурсий пользователями.
Сервис позволяет узнать информацию об экскурсии, проверить доступность
даты и оформить бронирование.

## Целевая аудитория

- Туристы и путешественники, которые хотят записаться на экскурсию.
- Организаторы экскурсий, которым нужно управлять расписанием.

## Предметная область

Предметная область — организация и бронирование экскурсий.
Экскурсия имеет название, стоимость, длительность и доступные даты.
Пользователь может забронировать экскурсию на конкретную дату.

## Основные сущности

- Пользователь
- Экскурсия
- Дата
- Бронирование

## Основные функции

- Показать информацию об экскурсии
- Проверить доступность даты для бронирования
- Рассчитать стоимость бронирования

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
